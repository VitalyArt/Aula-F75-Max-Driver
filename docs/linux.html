Install and open

  1. Download the DEB for your computer’s architecture. Open a terminal in the folder containing the downloaded file and run:

    Keep just one downloaded Aula DEB in that folder, matching your architecture.

    sudo apt update
sudo apt install ./AulaF75MaxDriver-v*_*.deb

  2. The package installs dependencies and the device access rule. Unplug and reconnect the keyboard and receiver after installation.

  3. Open Aula F75 Max Driver from your applications menu.

Connect your keyboard

USB cable: connect the keyboard in wired mode to upload an image or GIF and sync its clock.

2.4G receiver: connect the receiver and switch the keyboard to 2.4G mode to adjust lighting and read the battery.

Open Home to check that your keyboard or receiver is connected.

Inside the app

If something is not working

Keyboard not detected?

Reconnect the keyboard and receiver after installing the DEB. Use a USB data cable and the correct keyboard mode. Launch the app normally, without sudo.

Report a problem on GitHub

Include your operating system, app version, connection type and the step that did not work.
