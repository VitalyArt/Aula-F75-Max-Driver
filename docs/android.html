Install and open

  1. Download and open the APK. If asked, allow installation from the browser or file manager you are using, then install the app.

Connect your keyboard

  1. Connect the keyboard or 2.4G receiver to your phone or tablet using a USB OTG adapter. Open the app.

  2. Tap the USB icon at the top right (Grant USB access), then approve the Android permission prompt. Repeat for each connected device if prompted.

  3. Once permission is granted, the app can access the keyboard or receiver. Check the connection status on Home.

USB cable: connect the keyboard in wired mode to upload an image or GIF and sync its clock.

2.4G receiver: connect the receiver and switch the keyboard to 2.4G mode to adjust lighting and read the battery.

If something is not working

Keyboard not detected?

Check that your device supports USB OTG and your cable transfers data. Tap USB again and approve access; you may need to grant it again after reconnecting.

Report a problem on GitHub

Include your operating system, app version, connection type and the step that did not work.
